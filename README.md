# RPG Maker MZ 自定义主菜单 + 商店 UI 插件

## 文件
- `MZ_CustomMenuShopUI.js`

## 安装
1. 将 `MZ_CustomMenuShopUI.js` 复制到项目 `js/plugins/`。
2. 打开 RPG Maker MZ 的插件管理器，添加并启用该插件。

## 功能
- 自定义主菜单窗口布局（命令、状态、金钱）。
- 自定义商店窗口布局（帮助、命令、数量、状态、购买、出售）。
- 统一 UI 样式控制：
  - 窗口背景透明度
  - 字号/行高/描边
  - 普通文本强调色
  - 系统文本标题色
  - 可选隐藏窗口边框

## 说明
- 大部分参数支持直接在插件管理器中调整。
- 参数为 `0` 时通常表示“使用默认值”。
- 如果同时使用其他会改动 `Scene_Menu`/`Scene_Shop` 的插件，请将本插件放在后面。
